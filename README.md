# Authentication

A full-stack authentication application built using Next.js and MongoDB.

## Features
- User Registration
- User Login
- Password Hashing
- JWT Authentication
- MongoDB Database Integration

## Tech Stack
- Next.js
- TypeScript
- MongoDB
- Mongoose
- Tailwind CSS
- bcryptjs
- JSON Web Token (JWT)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Rajnishtripathime/Authentication.git
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the root directory and configure your environment variables:

```env
MONGO_URI=your_mongodb_connection_string
TOKEN_SECRET=your_secret_key
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
